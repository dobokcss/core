# DobokCSS
Micro framework HTML for developing responsive, mobile project

#### Quick Start via jsDelivr CDN

```html
<!-- Design Tokens -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/dobokcss/core@2.1.2/dist/tokens.css" />

<!-- Reset Module -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/dobokcss/core@2.1.2/dist/reset.min.css" />

<!-- Main Framework Bundle -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/dobokcss/core@2.1.2/dist/style.min.css" type="text/css" media="all" />
```

#### CSS
Copy-paste the stylesheet `<link>` into your `<head>` before all other stylesheets to load our CSS architecture (Tokens, Reset, and Main Bundle).
